# Bali · Java · Singapore — Luxury Itinerary

Private minute-by-minute travel document for **5–16 August 2026**.

## Run locally

```bash
cd itinerary
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Print / PDF

Use the **Print / Save as PDF** button in the app, or `Ctrl+P` / `Cmd+P`. Print styles expand all day cards automatically.

## Contents

- 12 fully detailed day itineraries (Bali, Mount Butak, Singapore)
- Expandable day cards with timelines, restaurant cards, attraction cards
- Atlas Beach Club & FINNS operator guides (verified schedules)
- Mount Butak trek data from Shelter Jelajah Indonesia (actual timings)
- Nusa Penida ferry schedules (Angel Billabong)
- Singapore: MBS, Gardens by the Bay, USS, Wings of Time, Jewel Changi
- Google Maps route links, booking links, budget breakdowns
- Mobile-friendly + print-friendly layout

## Data sources

Timings and prices researched June 2026 from official operator sites. Always re-verify hours and book in advance for Atlas, FINNS, Shelter Jelajah, and Ferizy ferry.
